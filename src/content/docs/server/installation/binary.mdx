### Build Binaries
Clone the repository, `cd` into it, and set the `VERSION` environment variable:
```sh
git clone https://github.com/juho05/crossonic-server.git
cd crossonic-server
VERSION=dev
```

Build `crossonic-server`:
```sh
go build -ldflags "-X github.com/juho05/crossonic-server.Version=$VERSION" -o crossonic-server ./cmd/server
```

Build `crossonic-admin`:
```sh
go build -ldflags "-X github.com/juho05/crossonic-server.Version=$VERSION" -o crossonic-admin ./cmd/admin
```

Create a user and database for `crossonic-server` via `psql`, the following is an **example**:

(`su postgres` on Debian)
```sql
CREATE USER crossonic WITH password 'crossonic';
CREATE DATABASE crossonic OWNER crossonic;
```
And exit `psql` via `\q`.

### Run `crossonic-server`
Generate a encryption key:
```
./crossonic-admin gen-encryption-key
```

Create a `.env` file for `crossonic-server`, the following is an **example**:
```ini
BASE_URL=http://crossonic:8080

DB_USER=crossonic
DB_NAME=crossonic
DB_PASSWORD=crossonic
DB_HOST=localhost
DB_PORT=5432
AUTO_MIGRATE=true
LOG_LEVEL=4

MUSIC_DIR=/music
DATA_DIR=/home/crossonic/data
CACHE_DIR=/home/crossonic/cache

ENCRYPTION_KEY=<your encryption key>
```
**See the [configuration guide](/server/configuration) for all options.**


## Create a user

To connect a client to the server you will need to create user credentials.

Replace `<name>` with your desired name:
```sh
./crossonic-admin users create <name>
```

When prompted enter your desired password and the user will be created for you. You can now
connect a [client app](/app) to your server with these credentials.
